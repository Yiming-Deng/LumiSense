# 灵映端侧性能测试报告

## 1. 测试范围与环境

本报告将“识别准确性”和“手机端运行性能”分开说明：前者采用公开或独立的数据集，后者在实际 Android 设备上测量。演示视频只用于展示功能，不作为准确率结论。

| 项目 | 说明 |
|---|---|
| 应用 | 灵映 Android 版 |
| 完整测试设备 | 小米 15，Snapdragon 8 Elite |
| 兼容适配目标 | 其他受支持的 Snapdragon 设备；OPPO Find X8，天玑 9400（MT6991） |
| 相机 | 前置摄像头 |
| 手势推理 | 端侧 NPU 硬件加速 |
| 手势模型输入 | RGB `640 x 640` |
| 端侧压力测试 | 5 分钟预热后连续运行 15 分钟，共 54,000 帧 |

受设备条件限制，本报告中的帧率、时延、功耗、温度和稳定性数据只来自小米 15。其他 Snapdragon 设备和 OPPO Find X8已实现 NPU优先的运行时适配，但未进行同等级真机性能测试，因此不引用小米 15数据作为这些机型的性能结论。

## 2. 静态手势识别测试

### 2.1 HaGRIDv2 官方评测集

HaGRIDv2 是公开手势数据集。最终手势模型使用官方评测集进行统一测试，包含 99,200 张原始图像和 139,414 个标注手部实例。该评测集与训练图像隔离。

下表为最终上机模型在该官方评测集上的实测结果。评测使用固定的 `640 x 640` 输入、同类重复框抑制、固定后处理和置信度阈值 0.32；手机端持续运行性能见第 4 节。

| 指标 | 结果 |
|---|---:|
| 手部检测 Precision | 98.12% |
| 手部检测 Recall | 99.11% |
| 34 类 Micro Accuracy | 98.69% |
| 关键点 PCK@0.10 | 92.85% |
| `no_gesture` 真负率 | 98.17% |
| 静态手势最低类别 Recall | 98.20% |

该指标按当前应用实际开放的静态手势类别统计。

### 2.2 公共无手背景测试

为观察背景误检，另使用 10,000 张公开无手图像进行独立测试，其中包括 5,730 张 COCO 2017 图像和 4,270 张 Places365 图像。图像在进入测试集前均经过人物和手部过滤，且与训练、验证和模型选择数据隔离。

本节是针对无手背景能力的独立补充测试，使用的是加入无手背景训练的静态评估模型；它不作为最终上机模型的 HaGRIDv2 准确率替代，也不与第 2.1 节的最终模型结果混合计算。

| 置信度阈值 | 发生误检的图像数 | 误检图像比例 |
|---|---:|---:|
| 0.15 | 27 / 10,000 | 0.27% |
| 0.32 | 10 / 10,000 | 0.10% |
| 0.50 | 3 / 10,000 | 0.03% |
| 0.70 | 2 / 10,000 | 0.02% |

该测试反映无手背景下的静态模型拒识表现，不以它替代真实用户场景的完整体验评价。

## 3. 指标说明

- **Precision（查准率）**：系统识别出的结果中，正确结果所占比例。越低表示误识别越多。
- **Recall（查全率）**：测试集中真实目标被系统识别出的比例。越低表示漏识别越多。
- **Accuracy（准确率）**：所有分类样本中，分类正确的比例。
- **Macro F1**：先分别计算每个类别的 F1，再对类别求平均，用于观察少数类别是否被整体平均值掩盖。
- **PCK@0.10**：预测关键点与真实关键点的归一化距离不超过手框尺寸 10% 的比例，反映关键点定位质量。
- **真负率（TNR）**：真实不属于目标类别的样本被正确拒识的比例，反映背景误检控制能力。
- **P50/P95/P99**：分别表示 50%、95%、99% 的样本不超过该时延。P95 越低，绝大多数使用场景中的等待感越弱。
- **FPS**：每秒处理的完整帧数。60 FPS 约对应每 16.7 ms 完成一帧处理。
- **端到端时延**：从相机帧进入应用，到识别结果显示或系统操作执行的总时间。
- **能耗/帧**：处理一帧图像消耗的能量，用于比较不同帧率或运行配置的能耗水平。

## 4. 手机端运行性能

小米 15 上完成 5 分钟预热和 15 分钟连续回放。测试期间使用端侧 NPU 推理；功耗测量开启了分析记录，因此功耗结果可视为偏保守的测量值。

| 指标 | 结果 |
|---|---:|
| 平均帧率 | 59.91 FPS |
| 端到端时延 P50 / P95 / P99 | 9 / 16 / 17 ms |
| 预处理时延 P95 | 11 ms |
| NPU 推理时延 P95 | 4 ms |
| 后处理时延 P95 | 2 ms |
| 平均功率 | 2.53 W |
| 功率 P50 / P95 | 2.09 / 4.81 W |
| 能耗 | 42.27 mJ/帧 |
| 温度变化 | 34.3°C 至 35.1°C |
| 系统热状态 | 全程为 0，未出现热降频 |

## 5. 结论

- 在 HaGRIDv2 官方评测集上，最终上机模型的检测 Recall 为 99.11%，34 类 Micro Accuracy 为 98.69%，关键点 PCK@0.10 为 92.85%；开放静态手势最低类别 Recall 为 98.20%。
- 在 10,000 张公共无手背景图像上，置信度阈值 0.32 下的误检图像比例为 0.10%。
- 在小米 15 上，手势识别链路的连续运行平均帧率为 59.91 FPS，端到端时延 P95 为 16 ms。
- 其他受支持的 Snapdragon 设备和 OPPO Find X8/天玑 9400采用 NPU优先、GPU/CPU兜底的兼容策略；由于没有对应实机，本报告不提供这些设备的性能保证。
