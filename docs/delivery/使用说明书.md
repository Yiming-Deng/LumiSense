# 灵映使用说明书

## 1. 第一次使用

1. 打开灵映，允许使用相机。
2. 将手或脸放入画面，等待画面上出现识别状态。
3. 需要在其他应用中控制时，打开“全局控制”，按系统提示开启无障碍服务。

不需要联网。相机画面只在手机本地处理。

## 2. 手势模式

### 显示模式

显示模式用于查看静态手势效果：

1. 进入“手势”。
2. 选择“显示模式”。
3. 做出一个静态手势并保持片刻。

支持 HaGRIDv2 中的静态手势。识别到的手势名称和对应动效会显示在画面中。

### 交互模式

交互模式用于演示动态手势，不显示静态手势动效：

1. 选择“交互模式”。
2. 等待顶部显示“已就绪”。
3. 按下表完成动作，看到提示后再做下一个动作。

| 动作 | 做法 | 结果 |
|---|---|---|
| 上滑 | 指向变停止、抓取变停止或握拳变停止 | 向上滑动 |
| 下滑 | 停止变反向停止，或指向变反向停止 | 向下滑动 |
| 左滑 | 保持允许的手型向左挥手 | 向左滑动 |
| 右滑 | 保持允许的手型向右挥手 | 向右滑动 |
| 放大 | 握拳变捏住 | 放大 |
| 缩小 | 张开手掌变握拳 | 缩小 |
| 双手放缩 | 双手握拳后向外或向内移动 | 实时放大或缩小 |

动作完成后请短暂回到自然状态。左右挥手有冷却时间，避免来回挥动重复触发。

### 没有触发时

- 确认整只手在画面内，避免背光和快速遮挡。
- 先等待“已就绪”，再开始动作。
- 双手放缩时，两只手大小不要相差太多。
- 如果刚刚触发过动作，等待状态恢复后再做下一次。

## 3. 面部模式

### 自由模式

1. 进入“面部”。
2. 选择“自由”。
3. 可选择关闭虚拟形象，或选择虚拟形象。
4. 对着前置摄像头做表情或转动头部。

支持：微笑、张嘴、嘟嘴、抬眉、左眼闭合、右眼闭合、双眼眨眼、向左转头、向右转头、点头和摇头。

虚拟形象会持续跟随真人的眼睛、脸部位置、头部方向和嘴眼形变。表情特效只在对应动作确认后出现。

### 表情挑战

1. 选择“挑战”。
2. 点击“开始挑战”。
3. 按屏幕题目完成表情或头部动作。
4. 每题完成后自动进入下一题，最后显示成绩。

挑战中只计算题目出现后的新动作。提前保持表情、做错动作或暂停期间的动作不计分。可随时暂停、退出或重新开始。

## 4. 全局控制

全局控制开启后，即使灵映退到后台，手势也可以控制其他应用：

1. 在手势交互界面打开“全局控制”。
2. 在系统设置中开启灵映无障碍服务。
3. 返回灵映，确认状态显示“全局控制已开启”。
4. 切换到其他应用后，按交互模式的动作操作。

悬浮窗只在“已就绪”或动作触发时出现。关闭“全局控制”即可停止后台识别和系统操作。

## 5. 使用建议

- 使用前置摄像头时保持脸部和手部有足够光线。
- 手势识别时尽量让完整手部进入画面。
- 双手动作时两只手都要保持可见。
- 面部模式中不要频繁遮挡脸部或快速离开画面。
- 手机发热或电量较低时，可关闭全局控制，减少持续识别时间。

## 6. 设备兼容性

应用会自动选择手机可用的推理硬件，不需要用户手动设置。小米 15已完成完整真机验证；其他受支持的 Snapdragon 手机和 OPPO Find X8/天玑 9400会优先尝试 NPU。若系统驱动不支持当前模型，应用会自动改用 GPU或 CPU，识别速度和功耗可能与小米 15不同。
