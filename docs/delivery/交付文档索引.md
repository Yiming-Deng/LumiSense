# 灵映公开源码文档索引

本目录提供灵映 Android 应用的最终说明材料。公开源码候选不包含 APK、签名材料、厂商运行库或模型权重。

## 完整运行边界

调试源码可以直接编译。完整识别功能需要按 `docs/MODEL_AND_VENDOR_ASSETS.md` 提供模型；Qualcomm QNN/HTP Release 还需要从 Qualcomm 合法取得 QAIRT SDK 和可再分发运行库。公开目录不提供现成安装包。

## 功能概览

- 软件名称：灵映。
- 主要能力：静态手势展示、动态手势交互、后台全局控制、面部表情与头部动作识别、虚拟形象和表情挑战。
- 手势识别标准评测：HaGRIDv2 官方评测集。
- 无手背景测试：由 COCO 2017 与 Places365 构成的独立公共无手图像集。
- 端侧运行测试：小米 15、Snapdragon 8 Elite、前置摄像头、端侧 NPU 硬件加速。
- 兼容适配：其他受支持的 Snapdragon 设备及 OPPO Find X8/天玑 9400；受设备条件限制，仅小米 15完成完整真机性能、功耗和稳定性验证。

文档只展示与最终功能和测试结论相关的信息。实验迭代、候选模型和内部归档材料不属于公开源码。
